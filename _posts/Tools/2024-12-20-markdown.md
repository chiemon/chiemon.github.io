## 显示徽标(badge)

- 官方地址：[shields.io](https://shields.io/)

### 实时显示 github 项目 star 数

*github 授权应用程序：[github-auth](https://img.shields.io/github-auth)*

1. 将 "https://github.com" 修改为 "https://img.shields.io/github/stars";
2. 结尾加上 ".svg";

以 TensorRT 为例 "https://github.com/NVIDIA/TensorRT"，则实时 start 图片为 "https://img.shields.io/github/stars/NVIDIA/TensorRT.svg"。


```markdown
![Github stars](https://img.shields.io/github/stars/NVIDIA/TensorRT.svg)
```

![Github stars](https://img.shields.io/github/stars/NVIDIA/TensorRT.svg)


**自定义徽标**

格式：**"\*.svg?[参数1]=[xxx]&[参数2]=[xxx]&[参数3]=[xxx]"**


1. style(样式)

    如果未指定，此徽标的默认样式为 `social`。

    | style           | view                                                         |
    | --------------- | ------------------------------------------------------------ |
    | `flat`          | ![Github stars](https://img.shields.io/github/stars/NVIDIA/TensorRT.svg?style=flat) |
    | `flat-square`   | ![Github stars](https://img.shields.io/github/stars/NVIDIA/TensorRT.svg?style=fflat-square) |
    | `plastic`       | ![Github stars](https://img.shields.io/github/stars/NVIDIA/TensorRT.svg?style=plastic) |
    | `for-the-badge` | ![Github stars](https://img.shields.io/github/stars/NVIDIA/TensorRT.svg?style=for-the-badge) |
    | `social`        | ![Github stars](https://img.shields.io/github/stars/NVIDIA/TensorRT.svg?style=social) |

2. logo(图标)

    单击 [simple-icons](https://simpleicons.org/) 上的图标标题进行复制。

    | logo       | view                                                         |
    | ---------- | ------------------------------------------------------------ |
    | `appveyor` | ![Github stars](https://img.shields.io/github/stars/NVIDIA/TensorRT.svg?logo=appveyor) |


3. logoColor(颜色)

    徽标的颜色（支持十六进制、RGB、RGBA、HSL、HSLA 和 CSS 命名颜色）。支持简单图标徽标，但不支持自定义徽标。

    | logoColor | view                                                         |
    | --------- | ------------------------------------------------------------ |
    | `violet`  | ![Github stars](https://img.shields.io/github/stars/NVIDIA/TensorRT.svg?logoColor=violet) |

4. logoSize(大小)

    通过设置使图标自适应调整大小 `auto`。对于一些较宽的徽标（如 `amd` 和 `amg`）很有用。支持简单图标徽标，但不支持自定义徽标。

5. label(标签)

    覆盖默认的左侧文本（空格或特殊字符需要 `URL` 编码！）

    | label         | view                                                         |
    | ------------- | ------------------------------------------------------------ |
    | `Github Star` | ![Github stars](https://img.shields.io/github/stars/NVIDIA/TensorRT.svg?label=Github%20%20Star) |
