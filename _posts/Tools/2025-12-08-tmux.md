## 启动鼠标滚动

1. 查看`tmux`版本

  ```bash
  # 大写V
  tmux -V
  ```

2. 编辑配置文件 `~/.tmux.conf`，若无则手动创建。将以下内容追加到配置文件中。

  ```bash
  # 版本 ≥ 2.1
  set -g mouse on

  # 版本 < 2.1
  setw -g mode-mouse on
  set -g mouse-resize-pane on
  set -g mouse-select-pane on
  set -g mouse-select-window on
  ```

3. 重新载入配置文件

  ```bash
  # tmux会话中
  tmux source ~/.tmux.conf
  ```

## 常用指令

- 创建新会话

  ```bash
  # 创建新会话
  tmux

  # 创建有特定名称的会话
  tmux new -s mysession
  ```

- 分离会话：`Ctrl+b`，然后按下 `d`

- 列出所有会话

  ```bash
  tmux ls
  ```

- 重连会话

  ```bash
  # 按会话索引重连
  tmux attach -t 0

  # 按会话名称重连
  tmux attach -t mysession
  ```

- 杀死会话

  ```bash
  tmux kill-session -t 0

  tmux kill-session -t mysession
  ```

- 会话中打开新窗口：在 `tmux` 会话中，按下 `Ctrl+b`，然后按 `c` 来创建一个新的窗口。
- 会话中切换窗口：在 `tmux` 会话中，按下 `Ctrl+b`，然后按 `p` 切换到上一个窗口，或按 `n` 切换到下一个窗口。
